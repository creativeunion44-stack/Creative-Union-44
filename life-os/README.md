# AI Life & Growth OS

Продукт, который показывает, как каждое дело двигает конкретную цель, и помогает заметить дела, которые никуда не ведут. Полное ТЗ: [`spec/TZ_v3.2.docx`](spec/TZ_v3.2.docx) (текстовая версия — [`spec/TZ_v3.2.md`](spec/TZ_v3.2.md)).

## Дорожная карта

1. **Неделя 1:** первый запуск ручной версии (в календаре — 16.11, 10:00). Каждый день план утром, энергия вечером, по воскресеньям обзор. Вводить голосом в приложении Claude; сохранять 20+ своих голосовых со смешанной RU/UA речью — на них потом проверяется распознавание (критерий приёмки).
2. **Недели 2–6:** 8–10 интервью на сегмент, сбор 200–300 дел для эталона.
3. **28.12 — шлюз этапа 0.** Критерий боли ≥ 60%, 15+ тестировщиков, сама пользуюсь 4+ недели → старт разработки. Иначе пересмотр и повтор этапа 0 один раз.
4. **Этап 1 (≈3–4 нед.):** проект Supabase (EU) из `0001_init.sql`, модуль `core` подключить к Edge Functions, экраны «Цели» в Lovable с кодом в этом репозитории.
5. **Этап 2 (≈2–3 нед.):** Telegram-бот (вебхук → Edge Function): ввод текстом, ИИ-разбор с уверенностью, «Входящие», отметка «сделано» → вклад.
6. **Этап 3 (≈2–3 нед.):** утренний план, напоминания (pg_cron + pgmq), 3 графика, недельный обзор, деньги, голосовые, экспорт и удаление.
7. **Этап 4:** юрист + DPIA, затем 5–10 тестировщиков.
